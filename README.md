# ReciclAR Admin

Este proyecto ha sido construido utilizando React y Vite.js para un desarrollo rápido y eficiente.

## Requisitos Previos

Antes de comenzar, asegúrate de tener instalado lo siguiente en tu sistema:

* **Node.js:** (Versión LTS recomendada. Puedes descargarla desde [https://nodejs.org/](https://nodejs.org/))
* **npm** (Viene instalado con Node.js)
* 
## Instalación

Sigue estos pasos para configurar y ejecutar el proyecto:

1.  **Clonar el repositorio:**

    ```bash
    git clone https://github.com/LeanApa/reciclar-admin.git
    
    ```

2.  **Instalar las dependencias:**

    **Con npm:**

    ```bash
    npm install
    
    ```

## Ejecución en Desarrollo

Para ejecutar el proyecto en modo de desarrollo con Vite:

```bash
npm run dev

```

Este comando iniciará el servidor de desarrollo de Vite. La aplicación estará disponible en tu navegador en la dirección que se muestre en la consola (normalmente `http://localhost:5173` u otro puerto disponible). Vite proporciona recarga instantánea en caliente (Hot Module Replacement - HMR) para una experiencia de desarrollo fluida.
